# Sales Checklist

## Product page

- [ ] One clear target user
- [ ] One clear problem solved
- [ ] 3 screenshots or one short GIF
- [ ] Supported OS list
- [ ] Known limitations
- [ ] Install steps
- [ ] Uninstall steps
- [ ] Contact/support route
- [ ] Refund/cancellation policy

## Pricing

- [ ] v1 early price decided
- [ ] Update policy decided
- [ ] License scope decided: personal / commercial / number of PCs

## Distribution files

- [ ] Windows installer tested
- [ ] macOS app tested
- [ ] Linux AppImage tested
- [ ] Zip file includes README
- [ ] File names include app name, version, OS, arch

## Legal / trust

- [ ] No third-party model/license violation
- [ ] No bundled secret keys
- [ ] No personal data collection without disclosure
- [ ] No unexpected network access
- [ ] Open-source notices included when necessary

## Customer support

- [ ] Support email or form exists
- [ ] Known issues section exists
- [ ] Crash reproduction steps are documented
- [ ] Version number is visible in the app or README
